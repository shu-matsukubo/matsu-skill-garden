# 表現方法一覧

## 表現

| 役割 | 表現 | 用途 |
| --- | --- | --- |
| 操作 | `〜する` | 手順の文末を動詞で揃える |
| 確認 | `〜を確認する` | 事実・状態を確かめる |
| 比較 | `〜を比べる` | 選択肢の違いを示す |
| 判断 | `〜を判断する` | 条件から結論を選ぶ |
| 必須 | `〜する` | 守る条件を明示する |
| 推奨 | `〜を優先する` | 例外を許容する選択の優先順位を示す |
| 任意 | `必要に応じて〜する` | 条件に応じて選べる処理を示す |
| 未確認 | `〜は未確認` | 失敗・不在と区別する |
| 見出し | `前提`、`制約`、`手順`、`結果` | 同じ階層を名詞で揃える |

## 参照

Skill・scriptの利用と文書方針の適用は、[参照動詞の方針](../../skill-design-policy/references/verbs.md)に従う。

## 選択

- 一覧に該当する場合は、その表現を使う。
- 該当しない場合は、周囲の文、関連する既存文書、目的に照らして推論する。
- すべての表現を一覧へ追加せず、繰り返し使う区別に価値がある場合だけ更新する。

## 根拠

設計方針と日本語出力方針の正本は、このリポジトリの方針Skill。2026-11-11のユーザー要求に基づく。上流principleを根拠とする生成Skillとは、根拠を区別する。
