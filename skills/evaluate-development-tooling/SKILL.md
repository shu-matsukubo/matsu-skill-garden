# 開発ツールと自動化の運用負担を比べる

- 作業時間に加え、覚えておく事項、確認の待機、注意の切り替えが継続的に減るかを見る。AIが生成できる成果物を増やす判断では、理解・選択・保守の負担も含める。
- ツールを比べるときは、チャットで思考を続けられるか、並行実行、利用枠・費用、操作の習得、既存手順への適合を確かめる。外部ツールは、設計意図の把握、必要部分だけの採用、取り外しのしやすさも見る。
- AIへ任せる仕事は、人が実行のきっかけや確認時期を覚えておく負担が減るかで選ぶ。通知、定期確認、レポート、収集と整理が候補になる。第2の脳の定期整理では、人が入力と整理方針の決定を担い、AIは承認済みの方針で整理し、改善候補を別のreportに記録する。
- 定期実行と手動起動を実際の使い方で比べる。自動実行の必要性、継続利用、人が時機を決める早さ、自動化の維持負担を確認する。使わなくなった起動方法は整理の対象とし、共通Workflowは維持する。
