# Webアプリの公開先を選ぶ

1. 採用候補のサービスごとに、現在の無料枠、超過時の停止や従量課金への移行、支出上限を設定できるかを確認する。
2. 機能とあわせて、費用の見通し、複数アプリの管理、デプロイと保守の負担、将来の料金体系が変わる可能性を比べる。
3. 個人開発ではCloudflareを優先候補に含め、採用前に使うサービス単位で無料枠と超過時の挙動を確認する。
