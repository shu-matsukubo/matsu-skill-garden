# 全体像から実践課題で学ぶ

まず技術の全体構造と主要概念を掴み、次の関係が辿れる地図を作る。

- どの技術が存在し、何の問題を解決するか。
- どの場面で使い、他の技術とどう関係するか。
- 問題に遭遇したとき、解決候補や詳細をどこで調べるか。

実際に使う課題へ進み、壁にぶつかったら原因を調べ、解決しながら必要な詳細仕様や制約を理解する。反復して使う知識は、実践を通じて精度を高める。

詳細を理解することと暗記することを分け、暗記にかける時間の価値を見極める。資格取得や体系学習は網羅性・用語の把握に役立つものとして位置付け、実践で問題を解決する価値と区別する。資格学習では、未知の技術を体系的に把握することを重視する。
